# Power-Distribution-CAD-2-Marine-Electrical-Design-1-Redundant-1000VDC-50Hz-440VAC-220VAC-Microgrid
Designed a 77600kW distribution grid using redundant EI insulated fiber optic cables to monitor higher order frequency noise, CAN Bus A/B Protocols for a 85m x 26m ship with a 26m catamaran channel.
