# Power-Distribution-CAD-2-Marine-Electrical-Design-1-Redundant-1000VDC-50Hz-440VAC-220VAC-Microgrid
Designed a 77600kW distribution grid using redundant EI insulated fiber optic cables to monitor higher order frequency noise, CAN Bus A/B Protocols for a 85m x 26m ship with a 26m catamaran channel. Utilizes \(\text{LiMn}_x\text{Fe}_{1-x}\text{PO}_4\) chemistry with an average global 0.6 C rate.

Order of Documents and Legend

The schematics representing this ProfiNET Control Fabric are ordered as follows:

* (Cadmatic) 1. Cable Tray Arrangement From Source to Load
* (ETAP) 2. Voltage Drop and Cable Selection
* (DraftSight) 3. 1000VDC 440VAC 220VAC Ship Microgrid of HSC Ferry
* (DraftSight) 4. AC/DC Bus General Arrangement
* (Excel) 5. Battery Regimes
